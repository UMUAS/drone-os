# drone-os
Runs on the drone's companion computer (e.g. Raspberry Pi or Jetson) using ROS2.

## Running on the drone

### Requirements
- Hardware
  - Jetson or Raspberry Pi
  - OAK-D Pro Camera
  - Connection to an ArduPilot Flight Controller
- Software / Operating System
  - Ubuntu 24.04
  - ROS2 Jazzy

You can follow instructions on how to set up ROS2 in the Wiki.
